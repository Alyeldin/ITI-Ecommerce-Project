# BookStore E-Commerce Platform 📚

A fully functional front-end e-commerce web application developed as a final deliverable for the ITI program. This project simulates a complete shopping experience, from browsing a database of books to user authentication and cart management.

## 🚀 Key Features

* **Dynamic Product Catalog:** Fetches and displays books in real-time using a RESTful API connected to a Supabase backend.
* **User Authentication System:** Fully functional Sign-Up and Login flows utilizing browser `LocalStorage` to manage registered accounts and active sessions.
* **Authentication State UI:** The navigation bar dynamically adapts to the user's state, hiding the shopping cart from guests and revealing it to logged-in users.
* **Interactive Shopping Cart:** Users can add products, specify quantities, and maintain their cart state across different pages.
* **Modern UI/UX:** Built with Bootstrap 5 for a fully responsive, mobile-first design, enhanced with SweetAlert2 for beautiful, animated user notifications.

## 🛠️ Technology Stack

* **Front-End:** HTML5, CSS3, Vanilla JavaScript (ES6+)
* **Styling & Icons:** Bootstrap 5.3, Bootstrap Icons
* **Backend / API:** Supabase (PostgreSQL)
* **Libraries:** SweetAlert2
* **Data Storage:** Window LocalStorage API
